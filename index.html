⚙️ Configuração inicial

Informe o Google Client ID para habilitar o acesso ao Drive.

⚠️ As credenciais ficam salvas só no seu navegador — nunca são enviadas a servidores.
1. Acesse console.cloud.google.com
2. Crie um projeto → ative a Google Drive API
3. Credenciais → OAuth 2.0 → Tipo: Aplicativo da Web
4. Em "Origens JavaScript autorizadas" adicione a URL do seu site GitHub Pages
5. Copie o Client ID e cole abaixo
